**B2：**在两个测试形状上，blockwise 路径未报错地接受了不支持的操作数字节并给出错误输出，而标准分支拒绝 e5m2。对所测扩展，这证实了预期的分支不对称。是否应由算子拒绝这些输入仍是 API 契约问题；当前 vLLM 调用方提供所要求的 dtype。

**B0：**三类填充视图的负对照在两个形状上都产生错误输出。B0 是已报告的 #55534 布局问题的回归证据，不是新发现。
