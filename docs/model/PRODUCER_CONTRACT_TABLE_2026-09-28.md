## Unprovided facts and next admission gate

- **Loop response:** default `/health` is not an EngineCore ping. [#36451](https://github.com/vllm-project/vllm/pull/36451) remains a proposal, not an available Lab producer. Even a successful ping would establish loop liveness, not token progress.
- **Per-engine progress:** the [V1 integration gate](../reviews/V1_RECORDER_VERDICT_INTEGRATION_GATE_2026-09-25.md) requires preserving each metric label partition, same-scrape counter and demand, freshness, and a stable label-to-PID/start-identity binding. The [G0 CPU gate](../../experiments/vllm-engine-binding-gate/LOCAL_CPU_GATE_2026-09-25.md) tests fail-closed joining rules, not a live binding. No per-engine recorder trigger is admitted by this table.
- **Lifecycle state:** pause/sleep and remote-KV waiting are not producer inputs in the released verdict. They are negative controls for any future progress-aware health proposal, not grounds to reinterpret historical bundles.

This table is a source-derived capability map, not a measured rate of missed diagnoses. It leaves the `external-runtime-observation-v1` fields and v0.2 verdict precedence untouched.
