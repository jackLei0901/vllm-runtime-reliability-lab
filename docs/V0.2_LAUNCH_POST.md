# v0.2 launch post draft

`/health` can stay green while an inference engine stops producing tokens.
vLLM Runtime Reliability Lab v0.2 packages one independently validated vLLM
base/fix campaign as a no-GPU replay: the base arm remains alive and returns 2xx
while token progress stops in event-queue backpressure; the fix arm preserves
progress while dropping four event batches.

After installing `vllm-runtime-dfx-lab` from the tagged source tree, run:

```bash
vllm-dfx replay results/vllm-zmq-backpressure-stage1-r3-20260916
```

The command verifies archived evidence, closed file identities, and the frozen
four-cell contract. It does not rerun the GPU experiment, claim production
readiness, or present #53859 as a lab discovery.

Feedback that helps: the exact command, platform, outcome, and any unclear or
failing step. This is a request to test a falsifiable artifact, not a request
for stars.
