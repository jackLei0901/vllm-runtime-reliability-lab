## One-booking order

1. **Read-only preflight, maximum 30 minutes.** Confirm both GPUs, disk space, venv Python/`torchrun`, exact vLLM/Torch versions, loaded NCCL library identity, `g++`, CUDA headers, `make`, and `command -v ninja` with the selected venv's `bin` on `PATH`. Verify the SSH host fingerprint against the user's independently supplied value. Identify the existing Inspector binary and hash it; build only if absent or mismatched. A build/load failure is an apparatus result, not a profiler result. Do not alter the source or thresholds live.
2. **Old evidence integrity and post-hoc audit.** Download the private archive, independently rehash it against the digest above, validate members and extract privately. Locate the healthy-control and hold cells and their digest-pinned `callbacks-before.json`, `callbacks-after.json` or `callbacks-during.json` files. Run `ptimer_posthoc_audit.py` once for healthy `after` and once for held `during` using the snapshot hashes from the retained manifests. The script requires rank-bound logs, a snapshot prefix and a clock marker for every selected channel event. It publishes only counts by rank: distinct occurrence IDs sharing a clock within `(communicator, channel, function, event kind)`, and newly observed clocks lower than the pre-window maximum in the same communicator/channel/kind. These are **post-hoc** checks; no threshold from the old protocol is retroactively changed. The published 73-class may shrink after function stratification; report that honestly. Adjacent inversions remain descriptive until a stream/order binding exists.
3. **Eager instrument control.** Fresh directory; `NCCL_PROFILER_PLUGIN` must name the digest-checked `.so`; use `NCCL_DEBUG=TRACE`, `NCCL_DEBUG_SUBSYS=INIT,PROFILE`, `NCCL_DEBUG_FILE=<cell>/nccl.%p.log`, and the same Inspector enable/verbose settings as the prior cells. Bound the two-rank command to 180 seconds. The runner saves rank-bound before/after snapshots and publishes their digests plus numeric pass. Score with `ptimer_standalone_score.py --mode eager` using those digests. Require exactly three new AllReduce occurrences per rank, complete per-channel START/STOP pairs, no zero or nonpositive pair, distinct and strictly advancing clocks, and no interval inversion on each channel. If the instrument control fails, **stop before graph**.
4. **Graph cell.** Fresh directory, identical runtime and plugin identity, 180-second external bound. Run `ptimer_standalone_replay.py --mode graph --sleep-cycles 1000000`; the runner must report six new AllReduce occurrences per rank, two numerically correct replays, and digest-pinned before/after snapshots. Score those snapshots with `ptimer_standalone_score.py --mode graph`. No retuning or repeat after seeing the result.
5. **Seal and stop.** Save raw logs, snapshots, commands, environment/build manifest and score JSON in a new owner-only private archive; hash it, copy it off-host and rehash the copy. Publish only closed counts, digests and software identities. Stop the instance only under the user's authorization and verify its platform power state separately; SSH loss alone does not prove billing stopped.

The local test gate completed before booking: `PYTHONPATH=src python -m unittest discover -s tests -q` ran **315 tests, OK, 15 skipped**; the 10 targeted pTimer tests passed. This is CPU/script evidence only. `ruff` was unavailable locally; `compileall` passed. Before transfer, record the reviewed commit and still verify the exact file hashes on the host; neither identity substitutes for the other.
